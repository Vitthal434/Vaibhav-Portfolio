01 / PRODUCTION SYSTEM Flask · NLP · Docker

ResumeIQ — ATS Resume Evaluator

Engineered a deterministic ATS scoring engine in Flask/Python that evaluates resumes against job descriptions with a weighted 50/30/20 formula. Features a 14-domain skill taxonomy, hybrid lexical (TF-IDF) + dense neural semantic embeddings (SentenceTransformer), ReportLab PDF export, and an optional non-hallucinated AI enhancement layer (local Qwen2.5 GGUF via llama.cpp with Google Gemini API fallback). Containerized and tested with a 163-test CI suite.
